# Cyber Hunt

Cyber Hunt is a real-time multiplayer cybersecurity social deduction game built with Node.js, Express, and Socket.IO.

## Features

- Create private rooms with generated room codes
- Support for 3 to 8 players
- Random Hacker assignment
- Random cybersecurity topic assignment
- Real-time clue submission
- Real-time voting system
- Automatic winner detection
- Duplicate clue protection
- Duplicate vote protection
- 30 cybersecurity-themed topics

## Technologies Used

- Node.js
- Express.js
- Socket.IO
- HTML
- CSS
- JavaScript

## How To Play

1. Create a room.
2. Share the room code with friends.
3. At least 3 players join.
4. Start the game.
5. One player becomes the Hacker.
6. Analysts receive the secret topic.
7. The Hacker sees "Unknown Topic".
8. Everyone submits one clue.
9. Players vote for the suspected Hacker.
10. Analysts win if the Hacker is identified.
11. Otherwise, the Hacker wins.
